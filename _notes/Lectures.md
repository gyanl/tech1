One 2-hour session per week. Dates may shift — treat the week numbers as canonical.

#### [[Lecture 1]] - Hello, Internet
*Week 1* — Ship a personal webpage before you understand it.

#### [[Lecture 2]] - Anatomy of a Web Page
*Week 2* — HTML, CSS, JavaScript — dissected via what you built.

#### [[Lecture 3]] - Talking to Servers
*Week 3* — HTTP/HTTPS, DNS, IP addresses, client-server architecture.

#### [[Lecture 4]] - Front-End in Practice
*Week 4* — Responsive design, design systems, Figma to code.

#### [[Lecture 5]] - Back-Ends and Databases
*Week 5* — Servers, SQL vs NoSQL, where your data actually lives.

#### [[Lecture 6]] - APIs
*Week 6* — REST, GraphQL, keys, and how software talks to software.

#### [[Lecture 7]] - AI in the Stack
*Week 7* — LLM APIs, what models can and can't do, AI features.

#### [[Lecture 8]] - Mobile Ecosystems
*Week 8* — iOS vs Android, native vs hybrid vs web, app stores.

#### [[Lecture 9]] - Cloud Computing
*Week 9* — IaaS, PaaS, SaaS; hosting, deployment, domains.

#### [[Lecture 10]] - How Software Gets Built
*Week 10* — SDLC, agile, version control. **Final project kickoff.**

#### [[Lecture 11]] - Studio 1
*Week 11* — Build sprint and crits.

#### [[Lecture 12]] - Studio 2
*Week 12* — Ship-ready: performance, security, privacy basics.

#### [[Lecture 13]] - Demo Day
*Week 13* — Final project presentations.
